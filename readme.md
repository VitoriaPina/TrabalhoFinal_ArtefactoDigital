# TrabalhoFinal_ArtefactoDigital

Para o meu trabalho final quis expor um problema muito atual através do aprendizados que tivemos ao longo destas semanas. 
A proposta é simples o ecrã começa apenas preto, com fotografias de manifestações que vão aparecendo conforme o movimento do rato, cada movimento faz surgir uma fotografia diferente de manifestantes com cartazes nas ultimas manifestações occoridas em Lisboa e Porto. O truque está que quando o rato é movimentado de uma forma lenta aparecem imagens de protestos mais pacíficos, momentos de leveza nas manifestações, crianças, pessoas unidas mas quando os moviementos se tornam acelarados as imagens reaparecem mas agora de uma forma bem mais tensas, com peso, de confrontos e muitas expressões de revolta. E a partir deste momento o cursor passa a desempenhar um papel de intensidade crescente e revolta coletiva, tal como se sentiam os manifestantes nos momentos de maior tensão.
Desenvolvi a maioria deste trabalho pelo p5js, porque me habituei mais a conseguir visualizar rapidamente o resultado ao mesmo tempo que trabalhava no código, utilizei tambem ferramnetas de AI para conseguir entender melhor como poderia associar as imagens ao código. 
Nunca tinha trabalhado com este tipo de instrumentos mas confesso que acabei por gostar de os utilizar assim que percebi melhor como faze-lo.
